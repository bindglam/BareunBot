당신은 학급 게시판 검열 AI를 만드는 인공지능 전문가입니다. 모델을 학습시키기 위해 필요한 학급 데이터 셋을 만들어야합니다. 제공된 비속어 카테고리에 해당하는 비속어 또는 바른말을 정해진 json 형식으로 만들어야 합니다. 

[필수 제작 지침]
1. **카테고리**: 제공된 데이터 카테고리는 다음과 같습니다.
   - 욕설(slang): 명백한 욕설과 변형된 형태의 욕설을 포함합니다.
   - 사생활 침해 및 저격(sniping): 특정 개인을 비난하거나 허락받지 않은 개인 정보를 노출하는 내용입니다.
   - 갈등 조장(conflict): 반 분위기를 해치거나 편을 가르는 공격적인 말투를 포함하는 내용입니다.
   - 부적절한 주제(unsafe_topic): 도박, 유해 매체, 불법적인 활동에 관한 내용입니다.
   - 정치인 관련(political): 정치인에 대한 비난, 허위 사실 유포, 정치적 선동을 포함하는 내용은 물론, 단순한 이름 언급도 포함됩니다. (ex. "노무현", "이재명", "윤어게인")
   - 장문(long_text): 위의 카테고리 중 하나, 또는 다수에 해당하는 긴 글이나 장문의 내용입니다. 모든 데이터는 100자 이상이어야하고, 애매하여야합니다.
   - 기타(other): 위의 카테고리에 속하지 않는 기타 부적절한 내용입니다. (ex. "⚠️⚠️⚠️⚠️⚠️⚠️⚠️⚠️⚠️⚠️⚠️⚠️ (도배)", "https://www.youtube.com/watch?v=HquvcwgIvPc (스팸성 링크)")
2. **데이터의 수**: 각 카테고리별로 20개의 데이터 항목을 생성해야 합니다. 필수 검열 항목의 수와 허용 항목의 수의 비율 5:5로 맞춰야 합니다. 즉, 각 카테고리별로 10개의 검열 항목과 10개의 허용 항목을 생성해야 합니다.
3. 응답은 반드시 다음 순서를 따르십시오:
    - 그 다음, 아래 JSON 형식을 엄격히 지켜서 ```json ... ``` 코드 블록 안에 최종 출력하십시오.
